Panduan Setup: Menggerakkan Turtle dari Website

Dari laptop kosong sampai kura-kura di turtlesim bergerak saat kamu menekan tombol di browser. Ikuti urut dari langkah 1. Tiap langkah punya bagian Hasil yang benar supaya kamu tahu langkah itu sudah beres sebelum lanjut.

Gambaran besar

Hasil akhir Kamu membuka website di browser, badge berubah hijau, posisi kura-kura tampil, dan tombol (atau W A S D) menggerakkan kura-kura di jendela turtlesim.

Browser tidak bisa bicara langsung dengan ROS 2. Jembatannya adalah rosbridge, yang mengubah topic ROS 2 menjadi pesan WebSocket (JSON). Di sisi web kita memakai pustaka roslib.

Yang kamu butuhkan

  • Ubuntu 24.04 (langsung, dual boot, atau VM dengan RAM minimal 4 GB)
  • Koneksi internet, sekitar 3 GB ruang kosong
  • Waktu sekitar 60 sampai 90 menit (langkah 1 paling lama karena mengunduh)
Cara membaca blok kode Blok gelap adalah perintah yang kamu ketik. Blok putus-putus adalah contoh keluaran yang seharusnya muncul. Angka dan waktu di keluaran boleh berbeda sedikit, itu normal. Tekan tombol Salin di pojok blok untuk menyalin perintah.
Langkah 1

Pasang ROS 2 Jazzy

Waktu: 20 sampai 40 menitTempat: terminal
TujuanROS 2 Jazzy Jalisco terpasang lewat paket apt resmi.

1.1 Atur locale (UTF-8)

sudo apt update && sudo apt install -y locales
sudo locale-gen en_US en_US.UTF-8
sudo update-locale LC_ALL=en_US.UTF-8 LANG=en_US.UTF-8
export LANG=en_US.UTF-8

1.2 Aktifkan repositori universe dan tambahkan sumber ROS 2

sudo apt install -y software-properties-common curl
sudo add-apt-repository universe
export ROS_APT_SOURCE_VERSION=$(curl -s https://api.github.com/repos/ros-infrastructure/ros-apt-source/releases/latest | grep -F "tag_name" | awk -F\" '{print $4}')
curl -L -o /tmp/ros2-apt-source.deb "https://github.com/ros-infrastructure/ros-apt-source/releases/download/${ROS_APT_SOURCE_VERSION}/ros2-apt-source_${ROS_APT_SOURCE_VERSION}.$(. /etc/os-release && echo ${UBUNTU_CODENAME:-${VERSION_CODENAME}})_all.deb"
sudo dpkg -i /tmp/ros2-apt-source.deb

1.3 Pasang ROS 2 Desktop

sudo apt update
sudo apt upgrade -y
sudo apt install -y ros-jazzy-desktop

Opsional tapi disarankan (dibutuhkan di pertemuan berikutnya untuk colcon build):

sudo apt install -y ros-dev-tools
Kalau ros-dev-tools gagal karena dependensiCek grep Suites /etc/apt/sources.list.d/ubuntu.sources. Barisnya harus berisi noble noble-updates noble-backports. Kalau kurang, edit berkas itu, lalu jalankan sudo apt clean && sudo apt update && sudo apt full-upgrade -y.
Hasil yang benar Cek dengan perintah di bawah. Kalau keluarannya ada, instalasi berhasil. 
ls /opt/ros
jazzy
Kalau ada masalah
  • Unable to locate package ros-jazzy-desktop: langkah 1.2 belum berhasil. Ulangi, lalu jalankan sudo apt update lagi.
  • Perintah curl ke GitHub gagal: cek internet. Di jaringan kampus, coba pindah ke hotspot HP.
  • Bukan Ubuntu 24.04? Jazzy hanya untuk 24.04. Cek dengan lsb_release -a.

Referensi resmi: docs.ros.org, Ubuntu (deb packages).

Langkah 2

Konfigurasi environment ROS 2

Waktu: 5 menitTempat: terminal
TujuanSetiap terminal baru langsung mengenal perintah ros2. Tanpa ini kamu harus mengulang langkah source di setiap terminal.

2.1 Source secara manual (untuk memahami)

source /opt/ros/jazzy/setup.bash
ros2 --help

Jika muncul daftar perintah ros2, environment sudah aktif untuk terminal ini saja.

2.2 Otomatiskan lewat ~/.bashrc

echo "source /opt/ros/jazzy/setup.bash" >> ~/.bashrc
source ~/.bashrc
Pakai zsh?Ganti setup.bash menjadi setup.zsh dan ~/.bashrc menjadi ~/.zshrc.

2.3 Cek variabel environment

printenv | grep -E '^ROS_'
ROS_AUTOMATIC_DISCOVERY_RANGE=SUBNET
ROS_DISTRO=jazzy
ROS_PYTHON_VERSION=3
ROS_VERSION=2

Urutan baris boleh berbeda. Setelah langkah 2.4 akan muncul satu baris tambahan ROS_DOMAIN_ID=....

2.4 Atur ROS_DOMAIN_ID (penting kalau satu jaringan ramai)

Semua komputer di jaringan yang sama dengan ROS_DOMAIN_ID yang sama akan saling melihat topic. Supaya tidak bentrok dengan teman, pilih angka 0 sampai 101 yang unik, misalnya dua digit terakhir NRP.

echo "export ROS_DOMAIN_ID=42" >> ~/.bashrc
source ~/.bashrc
Hasil yang benar Buka terminal baru (tanpa mengetik source), lalu jalankan: 
echo $ROS_DISTRO $ROS_DOMAIN_ID
jazzy 42

Referensi: Configuring your ROS 2 environment.

Langkah 3

Pasang turtlesim dan rosbridge, lalu coba

Waktu: 10 menitTempat: 2 terminal
TujuanKura-kura bisa digerakkan dengan keyboard dari terminal. Ini membuktikan sisi ROS 2 sudah sehat sebelum kita menyentuh web.

3.1 Pasang paket

sudo apt install -y ros-jazzy-turtlesim ros-jazzy-rosbridge-suite

3.2 Jalankan turtlesim

Terminal 1:

ros2 run turtlesim turtlesim_node

Jendela biru dengan satu kura-kura muncul.

3.3 Gerakkan dengan keyboard

Terminal 2:

ros2 run turtlesim turtle_teleop_key

Pastikan terminal 2 sedang aktif (diklik), lalu tekan tombol panah. Kura-kura bergerak.

3.4 Intip topic yang bekerja

Terminal 3:

ros2 topic list -t
/parameter_events [rcl_interfaces/msg/ParameterEvent]
/rosout [rcl_interfaces/msg/Log]
/turtle1/cmd_vel [geometry_msgs/msg/Twist]
/turtle1/color_sensor [turtlesim/msg/Color]
/turtle1/pose [turtlesim/msg/Pose]
Perhatikan hasilnya Nama topic dan tipe pesannya (di dalam tanda kurung siku) akan kamu butuhkan di langkah 7. Cari yang berhubungan dengan pose dan cmd_vel. 
ros2 topic echo /turtle1/pose
x: 5.544444561004639
y: 5.544444561004639
theta: 0.0
linear_velocity: 0.0
angular_velocity: 0.0
---

Gerakkan kura-kura lewat terminal 2 dan lihat angkanya berubah. Hentikan dengan Ctrl+C. Setelah selesai, tutup terminal 1 dan 2 juga.

Hasil yang benar Kura-kura bergerak dengan keyboard dan ros2 topic echo /turtle1/pose menampilkan angka yang berubah mengikuti gerakan.
Kalau ada masalah
  • ros2: command not found: lakukan langkah 2 lagi, lalu buka terminal baru.
  • Jendela turtlesim tidak muncul di VM: aktifkan akselerasi 3D di pengaturan VM, atau gunakan Ubuntu langsung.
  • Kura-kura tidak bergerak: terminal teleop harus dalam keadaan aktif, klik dulu terminalnya.

Langkah 6

Jalankan ROS 2 dan web

Waktu: 5 menitTempat: 2 terminal
TujuanTiga komponen berjalan: turtlesim, rosbridge, dan web. Di langkah ini web memang masih belum tersambung, itu disengaja.

6.1 Terminal 1: turtlesim + rosbridge

cd ~/starter-web-turtle
ros2 launch ros/web_demo.launch.py
[turtlesim_node-1] [INFO] ... Spawning turtle [turtle1] at x=[5.544445], y=[5.544445], theta=[0.000000]
[rosbridge_websocket-2] [INFO] ... Rosbridge WebSocket server started on port 9090

Pesan started on port 9090 menandakan jembatan siap. Biarkan terminal ini terbuka.

6.2 Terminal 2: web

cd ~/starter-web-turtle
npm run dev
  ▲ Next.js ...
  - Local:   http://localhost:3000
 ✓ Ready in 300ms

Buka http://localhost:3000 di browser.

Hasil yang benar (kondisi awal starter) Halaman "Turtle Web" tampil dengan badge oranye ("Terputus, mencoba lagi") dan tulisan "Belum ada data pose". Itu benar. Tugasmu di langkah 7 adalah mengubahnya jadi hijau.
Kalau ada masalah
  • Package 'rosbridge_server' not found: ulangi langkah 3.1 dan pastikan sudah source (langkah 2).
  • Address already in use di port 9090: ada rosbridge lama yang jalan. Tutup dengan Ctrl+C di terminalnya, atau pkill -f rosbridge.
  • Port 3000 terpakai: Next.js otomatis pindah ke 3001. Buka alamat yang tertulis di terminal.
Langkah 7 · Inti hands-on

Kerjakan tiga TODO

Waktu: 20 sampai 30 menitTempat: editor kode (misalnya VS Code)
TujuanMengganti subscriber dan menulis publisher sehingga web benar-benar mengendalikan kura-kura.

Buka folder proyek di editor (code ~/starter-web-turtle). Cari semua TODO:

grep -rn "TODO" lib components

Simpan berkas setiap selesai satu TODO. Next.js memuat ulang halaman otomatis, jadi kamu bisa langsung melihat efeknya.

  1. TODO 1Perbaiki alamat rosbridge
    Berkas lib/rosConfig.ts. Alamat sekarang salah port. Rosbridge berjalan di port yang kamu lihat di terminal 1 pada langkah 6.1.
    Petunjuk Format alamat: ws://localhost:PORT. Cari angka PORT di tulisan "started on port ...".
    Hasil yang benarBadge berubah hijau "Terhubung". Tombol teleop muncul, tapi belum menggerakkan apa pun.
  2. TODO 2Ganti subscriber ke topic pose
    Berkas lib/rosConfig.ts. Isi POSE_TOPIC dan POSE_TYPE dengan dua nilai yang kamu catat di langkah 3.4.
    Petunjuk Jalankan ros2 topic list -t dan cari baris yang berakhiran /pose. Nama topic ada di depan, tipe pesan ada di dalam tanda kurung siku.
    Hasil yang benarTeks x=5.54 y=5.54 theta=0.00 muncul, dan panah kura-kura tampil di kanvas.
  3. TODO 3Tulis publisher
    Berkas components/TeleopPanel.tsx. Ada dua tempat bertanda TODO 3a dan 3b. Objek pub sudah dibuat, kamu hanya perlu memanggil publish dengan pesan Twist. Fungsi twist(...) sudah tersedia untuk membuat pesan itu.
    Petunjuk pub.publish(pesan) mengirim satu pesan. Untuk terus mengirim selama tombol ditahan, panggil di dalam setInterval (sudah ada kerangkanya, isinya kosong).
    Hasil yang benarTahan tombol ▲ (atau W), kura-kura maju di jendela turtlesim. Lepas, kura-kura berhenti. Angka x dan y di web ikut berubah.

Mengapa 100 ms dan mengapa ada pesan berhenti?

ROS 2 menganggap perintah gerak itu terus-menerus. Selama tombol ditahan kita mengirim 10 pesan per detik. Saat tombol dilepas kita mengirim kecepatan nol, kalau tidak kura-kura akan terus bergerak dengan kecepatan terakhir.

Kalau ada masalah
  • Badge tetap merah setelah TODO 1: pastikan terminal 1 masih menyala dan menampilkan "started on port 9090". Port di ROSBRIDGE_URL harus sama.
  • Badge hijau tapi data tidak muncul: cek penulisan POSE_TOPIC dan POSE_TYPE. Awalan / di nama topic wajib ada, tipe pesan memakai /msg/ di tengahnya.
  • Data muncul tapi kura-kura tidak bergerak: TODO 3 belum diisi di kedua tempat, atau berkas belum disimpan.
  • Mau melihat pesan mentah: tekan F12, buka tab Network, pilih koneksi ws, lalu tab Messages.
